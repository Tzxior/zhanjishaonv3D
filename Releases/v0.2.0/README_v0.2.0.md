# 原型版本说明 v0.2.0

只在 `unity-prototype` 分支使用。单位数值来自用户提供的 `单位信息.csv`，不是已核实的原版官方数据。

## 本版实现
- 修正 `actions` 为对象数组的 JSON/C# 类型不匹配。
- 多种单位攻击按钮：步枪、机枪、手雷、炮击、狙击、空袭、鱼雷、舰炮等；有弹药容量的单位攻击消耗 1 发。
- 防空炮仅攻击空军；鱼雷机和潜艇仅攻击海军。
- 医疗兵治疗相邻友军（所损生命的 50%，100 AP）和鼓舞（等待 AP 减半，80 AP）。
- APC/运输舰向邻近友军补充燃料 +5 或弹药 +2；加油机/航母提供燃料 +5（80 AP）。
- APC、运输机、运输舰装卸陆地单位；选择载具后点击装载/卸载，载员必须相邻，卸载到相邻可通行空地。按 `resourceCapacity` 暂作载员数量上限，装卸各 100 AP。
- 要塞驻守形态才可攻击；移动后取消驻守。
- HUD 显示当前弹药、燃料和载员数量。

## 临时规则及未实现
- 间谍刺杀未给 AP，临时按 100 AP；真实伤害忽略防御。工兵布雷、间谍破坏建筑、航母专属舰载机停靠尚未实现。
- 运输舰目前只运载陆地单位，未完整实现两栖移动/海岸规则。
- 未实现燃料随移动消耗、完整战争迷雾、潜艇潜航切换和全部新行动的敌方 AI。
- 库存为本场内存状态，尚未持久化。
- 静态检查不等于 Unity 编译/运行测试；需要在 Unity 6.3 LTS 工程中编译并点击验证。
